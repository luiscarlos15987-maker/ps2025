# 💰 Analisador de Gastos

Um programa desenvolvido em Python para analisar gastos pessoais a partir do salário e das principais despesas mensais.

## 📌 Funcionalidades

- Cadastro do salário
- Cadastro de gastos com aluguel
- Cadastro de alimentação
- Cadastro de transporte
- Cadastro de internet
- Validação dos valores informados
- Cálculo do total de gastos
- Cálculo do saldo restante
- Cálculo do percentual do salário comprometido
- Identificação do maior gasto
- Análise percentual por categoria
- Alertas para gastos elevados
- Recomendações financeiras básicas

## 🛠️ Tecnologias utilizadas

- Python 3
- Git
- GitHub
- Visual Studio Code
